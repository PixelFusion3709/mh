프로젝트 소개 & 문제 해결 (Trouble Shooting)

🏫 학교 급식 및 일정 안내 웹 서비스

사용 기술: HTML, CSS, JavaScript, Python (Streamlit)

프로젝트 설명: 학생들이 매번 앱을 설치하거나 번거롭게 찾아보지 않고도 브라우저를 통해 학교 급식 식단과 학사 일정을 한눈에 확인할 수 있도록 만든 반응형 웹 서비스입니다.

💡 개발 과정의 어려움과 해결 방법 (Trouble Shooting)

  • 문제 상황: 초기 버전에서는 외부 공공 데이터 API를 불러오는 과정에서 데이터 포맷이 맞지 않아 화면이 자주 멈추거나 빈 화면이 출력되는 오류가 발생했습니다.
  • 원인 분석: 비동기 통신 처리 중 예외 상황(네트워크 지연 및 데이터 누락)에 대한 방어 코드가 누락되어 있었음을 파악했습니다.
  • 해결 방법: try-catch 구문과 데이터 유효성 검사 로직을 추가하여 에러 발생 시 사용자에게 친절한 안내 문구를 띄우도록 수정하고, 로딩 스피너를 도입해 사용자 경험을 개선했습니다.
