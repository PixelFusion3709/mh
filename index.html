AI & 머신러닝 프로그래밍에 대한 나의 탐구 철학

머신러닝 모델링은 단순히 높은 정확도(Accuracy) 수치를 얻는 것에서 끝나지 않습니다. "실제 사용자가 반응하는 웹 환경에서 모델 추론 Latency를 최소화하고, 노이즈 데이터에서도 안정적인 결과를 내는가?"가 핵심입니다. 본 프로젝트들은 웹 프레임워크인 Streamlit과 데이터 전처리, OpenCV 비전 처리 기술을 결합하여 직접 배포까지 완료한 결과물들입니다.

Computer Vision ML Web App

1. 실시간 웹캠 비전 기반 가위바위보 AI 게임

사용자의 손동작 카메라 프레임을 분류하여 AI와 실시간으로 가위바위보 대결을 진행하는 머신러닝 웹 앱

실행 서비스 바로가기
기술 스택 (Tech Stack)

Python, Streamlit, Teachable Machine / Keras, OpenCV, Pillow, Numpy

핵심 기능 (Key Features)

웹캠 이미지 실시간 클래스 분류(가위/바위/보), 확률 수치화, 승패 판단 로직 및 웹 인터페이스 구성

Trouble Shooting : 인식률 저하 및 웹캠 프레임 과부하 해결

🚨 문제 발생 (Problem) 사용자 환경마다 명암(조명) 차이와 배경 노이즈로 인해 손 모양 인식률이 60% 이하로 급감하고, 웹캠 비디오 스트리밍 시 Streamlit 리렌더링으로 인해 메모리 누수와 화면 멈춤 발생.
🔍 원인 분석 (Cause) 단일 조명 환경에서 수집된 학습 데이터셋의 과적합(Overfitting) 현상 문제 및 Streamlit의 매 프레임 전체 스크립트 재실행 구조로 인한 CPU 과부하.
💡 해결 모색 및 결과 (Solution & Result)
  • Data Augmentation: 밝기, 회전, 좌우 반전 이미지 데이터 1,200장을 추가 증강하여 재학습(분류 정확도 96.2%로 향상).
  • Image Preprocessing: OpenCV를 이용해 손 부분 ROI(Region of Interest) 영역을 추출하고 HSV 색상 영역 가공 처리.
  • Streamlit Cache (`st.cache_resource`): 모델 로더 메모리 캐싱 및 프레임 렌더링 주기를 조절하여 CPU 사용량 45% 감소 및 안정적 스트리밍 구현.
Open Data API GIS Location Search

2. 창원시 공공자전거 '누비자' 실시간 대여소 지도 서비스

창원 지역 공공 데이터를 활용하여 현재 내 위치 기반 최단 거리 누비자 대여소 검색 및 자전거 잔여 수량 파악 서비스

실행 서비스 바로가기
기술 스택 (Tech Stack)

Python, Streamlit, Folium, Pandas, Requests (REST API), Geopy

핵심 기능 (Key Features)

공공 데이터 API 실시간 JSON파싱, 하버사인(Haversine) 공식을 통한 최단거리 대여소 Top N 계산, Folium 인터랙티브 지도 시각화

Trouble Shooting : API 호출 제한 및 위경도 거리 계산 응답 지연 해결

🚨 문제 발생 (Problem) 사용자 요청 시마다 공공 API 전체 대여소(300여 개) 정보를 매번 새로 가져오면서 지도 로딩 시간이 4~5초 이상 소요되고, API 서버 일시 장애 시 웹 서비스가 Down되는 현상.
🔍 원인 분석 (Cause) 매번 전체 대여소 위경도에 대한 반복 거리 계산(O(N) 공간계산) 및 외부 REST API의 느린 HTTP 응답 속도로 인한 동기식 병목 현상.
💡 해결 모색 및 결과 (Solution & Result)
  • TTL 기반 API Caching (`st.cache_data(ttl=60)`): 1분 단위로 공공 API 데이터를 인메모리 캐싱하여 불필요한 요청 90% 이상 단축.
  • Vectorized Distance Math: Numpy 벡터화 연산 알고리즘으로 거리 계산 처리 속도를 0.02초 이내로 단축.
  • Exception & Fallback Handling: API 서버 장애 시 직전 최신 데이터를 반환하는 예외 처리 구문 작성으로 서비스 가용성 확보.
